Exercises the event gate: an `issues.milestoned` payload carries no triage-relevant evidence, so the run logs one audit line and stops before any read past the config — no metadata fetch, no model call, no mutation — and writes the skip record that is its whole outcome. The recording holds no answer file, which is what pins the zero-ask property. The snapshot is synthetic, written for this corpus; no real thread or provider transcript is reproduced.
