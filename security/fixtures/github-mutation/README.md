# github-mutation fixtures

The mutation surface of the corpus: the op set a hostile model answer — or a
hostile thread framing one — can reach stays on the declared sheet, reversible
in one click, visible where the work is, and never repeated. Each fixture
drives the real production module through a local fake; none imports another
test file.

- `two-size-label-invariant.test.mjs` — size rungs are a singleton in the
  applied label set, measured and never chosen. The rung-answer case is
  **EXPECTED RED TODAY**: an answer naming the measured rung itself red-runs
  the whole classification instead of proceeding with that rung; the fix
  belongs in `triage/`, not in this corpus.
- `off-sheet-refusal.test.mjs` — byte-exact sheet membership: off-sheet
  twins (`BUG`, `bug `, `⭐`) and labels a hostile thread body framed for the
  model never reach the forge as a write; a mixed answer applies only its
  sheet half.
- `mutation-ceiling.test.mjs` — the 3000-file listing ceiling fires before
  any model call (paginated or not), a 503 comment create makes exactly one
  attempt, and a moved branch tip is refused rather than force-overwritten.
- `comment-scope.test.mjs` — a human comment quoting the action's marker is
  never rewritten or collapsed; the upsert only ever adds under the action's
  own marker and only ever updates/deletes the action's own comments.

Deterministic and offline throughout: scripted model answers, scripted
transports, recording fakes. The `node --test` files run zero network and
zero wall-clock assertions.
